### 我在意的事

- **实用**：从真实遇到的问题开始，让工具融入日常工作。
- **简洁**：让默认设置容易上手，让功能和说明都清楚。
- **隐私**：说明数据来源、读取范围和联网行为，公开前检查敏感信息。
- **持续打磨**：记录变化和已知问题，根据使用反馈改进。
